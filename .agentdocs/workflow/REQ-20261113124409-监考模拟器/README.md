## 目标与范围

实现六屏观察、五类违规、正常干扰、固定六分钟考试、教学、三档难度、种子、结算、本地记录与真实复盘。不接入大模型或远程素材。

## 验收标准

- 六屏可直接举报且放大保留其他五屏；1440×900、1280×720 关键动作可辨认。
- 总数、并发、完整有效窗口、人员迁移、计分边界及同种子重现通过约束测试。
- 教学、正式六分钟、结算、复盘、重赛及暂停后台保护完整可用。
- 构建及有实际价值的自动化测试通过；浏览器完成全局流程和五类动作验证。

## 当前有效结论

- 使用 TypeScript + Canvas 2D + 原生 DOM，整数固定步长模拟。
- 使用程序绘制的统一卡通资产，保证六屏下物品与动作可读。
- 计分时间表预先固定；正常行为独立生成；复盘重放真实输入。
- 计分、动画和拾取共用整数模拟时钟；放大等比例显示，坐标同步处理留边与 DPR。
- 最近十局和最佳成绩按观察条件隔离；辅助调试、窄屏练习均单独标识。
