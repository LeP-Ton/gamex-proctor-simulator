- GitHub 插件不提供创建仓库和 Pages 配置接口，改用已登录的 `gh` CLI；不改变全局登录或 Git 认证配置。

- 使用已核实的 GitHub 官方 Actions：checkout v7、setup-node v7、configure-pages v6、upload-pages-artifact v5、deploy-pages v5；构建 Node.js 为 22。
