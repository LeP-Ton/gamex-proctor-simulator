## 方案与范围

上一版几何人物、平面描边和均匀色块仍明显像插画，单靠噪点不能解决。本轮将环境、人物和桌椅替换为本地照片质感素材，再按真实游戏状态组合，保留所有交互和事件机会。

- 使用内置 imagegen 生成四间空教室、两个公共洗手区、八种人物身份的四组动作及独立桌椅。素材为 AI 生成原创图片，不是真实录像或真人资料；运行时完全本地，不调用 AI。
- 正式 WebP 放在 `public/assets/photo-3/`，约 3.1MB；原始 PNG、完整生成提示词及透明背景参数可从该目录 README 和 `prompts.json` 追溯。
- 照片人物、桌面、前臂和物品分层，姿势随普通行为及作弊事件变化。照片本身的 alpha（透明度）生成保守拾取掩码，家具镂空保持透明，避免点中无形边框。
- 复查发现远近人物同高、伸出手臂衣色不符和公共区交换站距过大，已将人物/桌椅/物品宽高统一随深度缩放、衣袖匹配对应照片，并在准备阶段自然靠近再交换。人物外观用稳定哈希打散，减少跨考场整列重复。
- 所有素材解码后才允许开始；加载失败保持时钟为零并提供重试。既有历史入口继续可用。
- 新画面版本 `photo-3` 隔离最佳成绩，事件随机与计分规则保持不变。经典版与 V2 监控版分别使用冻结模块复盘。

## 主要文件

- `geometry.ts` / `canvas.ts`：照片帧组合、实际透明轮廓拾取、轻微画面颗粒、图片解码缓存。
- `photo-assets.ts` / `scripts/prepare-photo-assets.py`：纯数据裁剪帧、头部锚点及透明掩码；Pillow 仅作为可选离线资源准备工具。
- `monitor-geometry.ts`：冻结 V2 几何，和已有经典版并存。
- `main.ts` / `style.css` / `config.ts`：素材载入和重试、三代视觉标签及新局版本。
- `tests/`：照片透明、镜像、缩放、家具镂空、三代兼容与加载回归。
