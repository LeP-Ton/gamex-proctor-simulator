# 双版本分支发布

## 基本信息

- 需求 ID：REQ-20261116130906。
- 来源：用户要求将“会话-14”的插画可玩首版与当前写实版拆成两个分支，同时部署到 GitHub Pages。
- 创建时间：2026-11-16 13:09:06，Asia/Shanghai。
- 状态：两游戏分支已在公开 GitHub 创建；两版测试/构建、站点组装及本地浏览器验收通过；main 发布代码尚未提交，最终双版本云端部署和线上访问待验。
- 权威入口：本仓库 main 分支的本目录。游戏源码分别在两个版本分支维护。
- 关联聊天：2026-11-16 本次双版本拆分聊天，会话-57—58；聊天 ID 不可获取。

## 目标与范围

- 独立维护 `codex/illustrated` 插画首版和 `codex/realistic` 当前写实版。
- 一个 Pages 站点同时保留根目录选择页、`/illustrated/` 与 `/realistic/` 两个可玩入口。
- 发布时锁定两版源提交并组合成单一产物，任一版失败不替换已发布站点。
- 两版设置和成绩隔离，写实版继续读取原保存键，兼容旧根书签。
- 不修改游戏玩法、平衡参数或后续写实版动作表现；不删除历史提交或改变 Sites 私有首版。

## 验收标准

- 公开仓库两个命名分支可追溯到明确基线，插画版确为首版运行源码而非新版切换旧渲染。
- 两版分别通过自身核心测试和生产构建；组合产物包含两个完整应用、选择页和源提交清单。
- 1440×900、1280×720 均可从两个入口开始游戏，并完成实际指针举报、结算保存和复盘。
- 同源访问时两版保存键不同，写实原档不被插画入口改写；旧 `?v` / `?debug` 书签正确进入写实版。
- main 云端组合测试、两版构建及单次部署通过，线上入口和资源可访问，清单与实际源 SHA 一致。

## 当前有效结论

- 插画分支当前 `40616f5`，基于 `6e3af47`；写实分支当前 `2e13e97`，基于 `f258a19`。完整 SHA 与核实证据见[阶段记录](20261116130906-双版本发布.md)。
- 没有可核实的“会话-14 专属 SHA”；首交付 `be6f57f` 与 `6e3af47` 的 `src/`、`public/`、`tests/` 和 `package.json` 一致，据此恢复插画版；仅增加存档隔离及部署适配。
- main 仅做选择页与组合发布。版本分支薄工作流通过 `workflow_dispatch` 请求 main，main 一次解析两版固定 SHA，再统一上传部署，避免环境分支策略和互相覆盖。
- 插画保存键 `gamex-proctor-illustrated-v1`；写实保留 `gamex-proctor-v1`，原数据不改写。路径不同不能代替同源存档隔离。
- 根选择页不加载游戏；旧根查询书签转写实子路径并保留查询和片段。

## 进展与待办

- 已完成：两公开源码分支、插画 16 项测试与构建、写实 36 项测试与构建、4 项组装测试、本地组合站点 8 组浏览器验收。
- 本地浏览器包含 20 次真实指针举报、两种尺寸、真实完成局与存档隔离、写实原档字节不变和复盘、旧书签跳转、无控制台错误及 404。
- 两版本分支的云端 hook 已成功请求 main；当时 main 仍使用旧发布流程，不算最终双版本部署验收。
- 待完成：main 代码提交、组合云端工作流、最终 Pages 部署及线上检查；最终结果由主代理补齐。
- 用户对双版本入口和体验的人工反馈尚未确认。
