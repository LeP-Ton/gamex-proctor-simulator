## 目标与验收

- 插画、照片、3D各自独立源码分支、独立测试构建、独立部署仓库、独立 Pages 产物与环境；更新任一版不构建、重部署或覆盖其他版本。
- main 只维护原根地址选择页与旧书签跳转，不联合构建三个游戏。
- 三独立站均可实际开局、举报和结算；每站 deployment.json 精确追溯源仓库、版本分支、完整 SHA 与源 tree。
- main 明确区分三种画面和会话来源；旧根 motion-4 跳照片站，其余旧根 v/debug沿用3D站；三兼容子目录完整保留查询与片段跳转；main 发布失败不影响游戏站。
- 三站同 origin 下显式隔离保存键，原插画与3D历史保留。
- 照片版从可核实的会话54 motion-4基线恢复，只适配独立保存和发布，不混入后来的3D画面。
- 保留组合阶段的历史验证，说明其发布方案已被用户澄清要求替代。独立两站先完成后，再进行写实效果升级。
