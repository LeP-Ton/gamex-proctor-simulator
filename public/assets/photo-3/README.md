# 照片质感游戏素材

本目录是《监考模拟器》`photo-3` 视觉版本的正式打包资产。人物、考场、家具和公共洗手区均为 AI 生成的原创素材，不是现实学校的监控录像，也不是真人身份或监控资料。照片质感只用于游戏画面；游戏界面保留模拟标识。

原始 PNG 保存在本项目工作区外的 Codex `generated_images/` 目录，本目录的 WebP 是运行和发布时使用的文件。完整生成提示词及来源映射见 `prompts.json`。人物图中近乎全透明像素内的彩色 RGB 是原始透明图的数据，实际 alpha 通常仅为 1–4/255；无需修复，不参与命中。

## 文件与帧布局

| 文件 | 像素尺寸 | 用途与帧顺序 |
| --- | --- | --- |
| `classroom.webp` | 1642×958 | 四间无人物教室背景，2 列 × 2 行，共 4 帧 |
| `public.webp` | 2172×724 | 两个公共洗手区背景，2 列 × 1 行，共 2 帧 |
| `people.webp` | 1086×1448 | 第一组 4 个稳定人物身份，四行动作为书写、侧身、伸展、站立，共 16 帧 |
| `peopleB.webp` | 1199×1312 | 第二组 4 个稳定人物身份，动作顺序相同，共 16 帧 |
| `furniture.webp` | 1312×1199 | 帧 0/1 为整桌，2/3 为椅子；4/5 为桌 0 的桌面/桌架，6/7 为桌 1 的桌面/桌架 |

人物动作行按原图实际间隙划分，不能直接把图片等分为四行。所有透明帧的源裁剪矩形、头部锚点和拾取掩码均保存于 `src/render/photo-assets.ts`。帧裁剪使用 alpha ≥16 的内容范围；命中使用 alpha ≥128，并保守检查覆盖像素，不扩张至透明边缘。家具镂空保持可穿透，淡阴影不作为实体命中区域。

## 离线处理

正常安装、启动、构建和游玩无需 Python 或 Pillow。仅在重新准备原始素材时，需要独立的可选 Python 环境：

```sh
python3 -m venv /tmp/proctor-photo-assets-venv
/tmp/proctor-photo-assets-venv/bin/pip install Pillow
/tmp/proctor-photo-assets-venv/bin/python scripts/prepare-photo-assets.py \
  --people /原始素材/人物A.png \
  --people-b /原始素材/人物B.png \
  --classroom /原始素材/教室.png \
  --furniture /原始素材/家具.png \
  --public /原始素材/公共洗手区.png
```

命令须在项目根目录执行。脚本只转换文件格式、提取实际裁剪边界和透明度元数据，不重绘、调色或覆盖原始 PNG。透明素材使用无损 WebP，alpha 与原图逐像素一致；不透明环境背景使用高质量 WebP。若更换原图尺寸或布局，应先校准脚本内的动作行边界与头部锚点，再生成元数据及运行测试。

运行时图片从本站静态目录加载，解码后在本地 Canvas 中组合与播放动作。运行时不调用 AI、图片生成接口或远程素材服务。
