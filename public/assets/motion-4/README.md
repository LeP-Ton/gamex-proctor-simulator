# 连贯动作版本新增人物素材

`peopleC.webp` 是《监考模拟器》`motion-4` 版本新增的 12 个稳定人物身份。素材由内置 imagegen 工具生成，为原创照片质感游戏素材，不是真人身份资料或真实监控录像。运行时只加载本站本地文件，不调用图片生成或推理服务。

原始图为 1536×1024 RGBA PNG。本目录的 WebP 采用无损编码，重新解码后与原图 RGBA 逐像素一致；未重绘、调色、清理透明边缘或改变人物。原图近透明区域残留的 RGB 颜色不代表实际背景，拾取只按真实透明度进行。

## 帧与身份

| 帧号 | 身份与姿势 | 对应关系 |
| --- | --- | --- |
| 0—5 | 男性身份 1—6，坐姿 | 与 12—17 一一对应 |
| 6—11 | 女性身份 1—6，坐姿 | 与 18—23 一一对应 |
| 12—17 | 男性身份 1—6，站姿 | 身份和衣服沿用 0—5 |
| 18—23 | 女性身份 1—6，站姿 | 身份和衣服沿用 6—11 |

实际人物并不对齐等分网格。已按透明间隙校准列边界 `[0,304,544,784,1024,1264,1536]`、行边界 `[0,254,510,766,1024]`，避免把下一行头发或邻人的衣袖裁进当前帧。

`source-frames.json` 保存每帧源裁剪矩形、原图头部坐标和裁剪后的局部头部坐标，便于重新核对。运行数据位于 `src/render/motion-photo-assets.ts`；通过 `photo-assets.ts` 的 `PHOTO_ASSETS.peopleC`、`photoFrame`、`photoHead` 与 `containsPhoto` 使用。`headX/headY` 相对于该帧裁剪矩形，运行时转换为画面中的实际头部坐标。

帧边界按 alpha≥16 提取，拾取按 alpha≥128 提取保守 RLE（连续区间编码）掩码；每个掩码单元覆盖最多 2×2 源像素，所有覆盖像素都不透明时才可命中。头部锚点经过同一掩码验证，透明角落不扩张为命中区。

## 离线格式准备

正常安装、构建和游玩不需要 Python 或 Pillow。只有重新准备原始素材时才需要可选环境：

```sh
python3 -m venv /tmp/proctor-motion-assets-venv
/tmp/proctor-motion-assets-venv/bin/pip install Pillow
/tmp/proctor-motion-assets-venv/bin/python scripts/prepare-motion-assets.py \
  --people /原始素材/人物C.png
```

脚本输出无损图片、独立新增元数据和源帧清单，并扩展公共素材注册表；现有 `photo-3` 五个素材数据保持不变。若先重新运行 `prepare-photo-assets.py`，最后再运行本脚本恢复新增注册项。更换原图尺寸或人物布局时应重新校准源边界与头点，不能直接按网格等分。

完整提示词及原始文件映射见 `prompts.json`。旧版照片素材及冻结复盘几何继续保留，新增身份不会覆盖旧记录中的人物外观。
